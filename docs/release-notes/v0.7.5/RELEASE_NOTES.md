# Release v0.7.5 — Native menus and a Minimal layout

## Features

- Add File, Edit, Format, Insert, View, Presentation and Help menus to the menu bar, so every command stays reachable even when its toolbar button is hidden (#148)
- Add a Minimal layout in *View → Customize Layout…* that clears the top toolbar and keeps workspace, statistics, zoom, AI and code view on the bottom bar (#148)

## UI/UX

- Ask before a layout preset replaces your own custom toolbar arrangement, and keep existing layouts as they are after updating (#148)
- Stop file tree rows from jumping when you hover over folders or unsaved files (#149)
